The problem

Five tools, five bills, no single page.

A consultant sends a Linktree for links, a Calendly for meetings, a Google Form for enquiries, a WhatsApp number for everything urgent and a PDF brochure over email. Nothing shares an address, a look, or a record of who got in touch.

Scattered

No single address

The link you hand out depends on what you happen to want that day.

Generic

Looks like everyone

Link-in-bio tools give every profession the same stack of grey buttons.

Leaky

Enquiries get lost

Forms land in an inbox; nobody knows what is open or answered.

Manual

Same questions daily

Pricing, timings and process get retyped by hand, forever.

The idea

One page, assembled from blocks.

Nothing in the product is tied to an industry. A page is an ordered list of blocks, each holding its own content and wording — so a photographer, a doctor and an elected representative build genuinely different pages out of the same parts.

Surface 02 · The page editor

Built like a design tool, not a settings form.

Drag and drop that behaves

  • Every block in the library is a tile with a miniature of its own layout — rows, grids, columns, a chat bubble, a map pin
  • A ghost card follows the cursor; a drop line with a label tracks where it will land
  • The canvas auto-scrolls near its edges, and the whole thing runs on pointer events, so it works on touch
  • Filter by category or search all 41

Edit on the page

  • Click any heading or subtitle on the canvas and type — the nav and mobile tab update with it
  • Hover a block for its toolbar: move, duplicate, hide, delete
  • Properties panel carries every option, with add / reorder / remove rows for list blocks
  • Undo and redo across every change — ⌘Z, ⇧⌘Z, Delete to remove, Esc to deselect

Surface 02 · Live editor

Three panes: outline, fields, live preview.

Left
Layout, theme and type. Every section with a drag handle, eye and delete, plus Add custom section. Beneath it the current colour with twelve presets, a font pairing picker, and sliders for line height and base font size that retype the preview as you drag.
Middle
Field by field. Avatar with left, centre and right alignment, then one row per field — name, title, tagline, status chip, organisation, numbers, phone, email, website, location. Each drags to reorder, hides, deletes and edits inline. Removed rows return from a chip list.
Right
An editable preview. Zoom out, in, fit-width, and a desktop / mobile toggle. Click the name, title or tagline and type straight onto the preview; hover the avatar for a picker with presets, a URL field, or an upload from the device.

Assistants

Two assistants. One faces visitors, one faces you.

Public

Answers from your own words

The visitor assistant retrieves from a knowledge base you write, quotes the passages that match, and cites which entries it used. Below a confidence threshold it says it does not know and offers a booking instead of inventing an answer.

Public

Fed by documents

Drop in notes, FAQs or policies. Text formats are read, split into passages and tagged automatically; each document is listed with its entry count and removable in one click. A retrieval tester shows exactly what a visitor would get.

Owner only

Ask about your account

A private assistant that reads your live figures: views and your best day, click rate with strongest and weakest link, bookings with their value and conversion, open requests by category, and which blocks are not showing and why.

In the demo, retrieval and answering run entirely in the browser — no API key, no external service, nothing leaving the page.

Surface 03 · The admin

The dashboard only shows tools you use.

Every tab is gated on a block being present. No Services block, no Appointments tab. Add a Request desk and Requests appears the moment you return. What is missing is listed, with the block that unlocks it.

Always available

  • Overview — views, clicks, bookings and subscribers, a seven-day chart, and the live/hidden/empty state of every block
  • Profile — identity, contact and page settings, as its own section
  • Ask about my account — the private assistant
  • Live editor and Design & blocks
  • Example profiles — four finished pages to explore

Unlocked by a block

  • Links, Services, Experience, Reviews, Clients, Progress, Gallery, Events, Jobs — content for the matching block
  • Appointments — needs Services
  • Requests — needs the Request desk
  • Subscribers — needs the Newsletter
  • Knowledge base — needs the AI assistant
Where the demo stands

What is real today, and what comes next.

Working now

  • Every screen, block and flow described here, running in the browser
  • Edits in the admin appear on the public page immediately; layout and design persist between visits
  • Retrieval, document ingestion and both assistants run locally
  • vCard download and Web Share are genuinely real
To build

For production

  • Accounts, authentication and a database in place of browser storage
  • Real email and SMS for confirmations; payments for paid bookings
  • Hosted embeddings and a language model for the assistants
  • File storage for images and documents; custom domains per profile
  • An analytics pipeline behind the numbers on the dashboard

Nothing in the demo pretends to be connected. Forms simulate a request and say so; the assistants explain that they answer from a local knowledge base.

In short

A page builder anyone can operate.

The demo runs today at localhost:3000 — the public page, the editor at /webview, and the dashboard at /admin. Four example professions are one click apart.
